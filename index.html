ضع الاستراتيجيات على جهازك

التثبيت الكامل يعمل من رابط موقع منشور عبر HTTPS (مثل GitHub Pages)، وليس من ملف HTML المحلي. بعد فتحه أول مرة عبر الإنترنت والتأكد من حفظ الملفات، يمكن تصفح الاستراتيجيات والكتيب الرقمي دون اتصال. ملف PDF يحتاج إلى تنزيل منفصل.

📱

iPhone / iPad

افتح الموقع في Safari، ثم مشاركة ← إضافة إلى الشاشة الرئيسية، وفعّل «فتح كتطبيق» إن ظهر.

📲

Android

في Chrome افتح قائمة ⋮ ثم اختر تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.

💻

Windows / Mac

في Chrome أو Edge استخدم أيقونة التثبيت في شريط العنوان أو قائمة المتصفح. وعلى Mac مع Safari استخدم File → Add to Dock إذا كان متاحًا.

لو خيار التثبيت لا يظهر: تأكد أنك على رابط HTTPS للموقع المنشور، وليس الملف الذي حملته. في iPhone افتح الموقع من Safari. إن استمر الأمر، حدّث الصفحة أو أعد فتحها بعد نشر الملفات كلها في جذر المستودع.
