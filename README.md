# تطبيق 101 استراتيجية في التعلم النشط — نسخة GitHub الخفيفة

## طريقة الرفع
فُك ضغط الملف 101-GitHub-Upload.zip، ثم ارفع **جميع الملفات والمجلد icons/**
إلى جذر المستودع مباشرة، بحيث يكون `index.html` في المستوى الأول.

الإعداد: إشراف الأحياء بتعليمية البريمي.
إعداد: د. سمية بنت سالم بن محمد النعيمي، وأ. محمد سيد عبد الستار سليم.
المصدر الأساسي: كتاب «101 استراتيجية في التعلم النشط» لماشي بن محمد الشمري.

## تفعيل الموقع
Settings → Pages → Build and deployment → Deploy from a branch
ثم Branch: main وFolder: /(root)، ثم Save.

## ملاحظات
- هذه الحزمة **لا تحتوي على ملف PDF الثقيل** حتى يسهل تنزيلها ورفعها.
- افتح `booklet.html` لقراءة الكتيب أو حفظه PDF من خيار الطباعة.
- التثبيت كـ PWA يتطلب موقع HTTPS منشورًا مثل GitHub Pages.
- احتفظ بمجلد `icons` كما هو.
